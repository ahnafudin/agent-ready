# Anti-slop: copy

Every text a person reads: UI strings, docs, README, changelog, commit messages, PR descriptions.

- Say the specific thing. "Exports 4K in 90 s on a 2020 laptop" beats "blazing-fast exports".
- A number is measured and sourced, or it is not written.
- Cut filler: "seamless", "robust", "leverage", "unlock", "elevate", "empower", "cutting-edge",
  "game-changer", "delve", "it's worth noting", "in today's fast-paced world".
- No "it's not X, it's Y" framing, no lists of three written for rhythm, no question headlines.
- Short sentences, active voice, one idea each. Dashes and bold are rare, not a style.
- No emoji in docs, UI copy or commit messages.
- A heading names what follows; it does not tease it.
- A changelog entry says what changed for the user, not which files moved.
