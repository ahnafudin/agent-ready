# Anti-slop: UI

Slop UI is the look every generated screen shares. A screen should look like this product.

- Colours, spacing, radii and type come from the project's design tokens, never a raw value.
- Decoration needs a job. No gradient blobs, frosted cards, glows or sparkle icons by default.
- No emoji as icons. One icon set, one stroke weight.
- No invented content: no fake metrics, customer logos, testimonials, ratings or "trusted by" rows.
- No placeholder text in a shipped screen ("Lorem ipsum", "Feature one", "John Doe").
- Design every state: empty, loading, error, very long text, one item, many items.
- Build hierarchy with size and spacing, not by centring and bolding everything.
- A button says what it does ("Export video"), not "Get started" or "Learn more".
- Text contrast meets WCAG AA; every control has a label and a visible focus state.
- The layout holds at phone width without sideways scrolling.
